# 算电通 — AI数据中心电力交易智能分析平台

面向AI数据中心的电力交易辅助决策平台，集成市场行情监控、日前申报、负荷调度、绿电合规、需求响应、结算对账等全流程功能，并与飞书7大专业智能体团队实时联动。

## 功能模块

| 模块 | 说明 |
|------|------|
| 工作台 | 实时状态栏、紧急告警、KPI卡片、今日待办、偏差监控、申报审批流、操作日志 |
| 市场总览 | 8省现货价格对比、中长期行情、新能源占比、市场动态 |
| 电价分析 | 日前/实时电价曲线、峰谷价差、价格预警设置 |
| 负荷与算力调度 | 负荷构成、算力-电力协同调度、灵活性资源管理 |
| 交易策略 | 96点申报曲线编辑器、日前申报工作台、购电策略模拟器、收益测算 |
| 中长期签约 | 合同管理、购电策略模拟、合规检查 |
| 绿电合规 | 绿电消纳进度、绿证采购、合规台账、42号令达标跟踪 |
| 需求响应 | 邀约管理、收益计算器、报名执行 |
| 结算对账 | 日清分、月度结算、盈亏归因、CSV导出 |
| 交易日历 | 交易节点提醒、申报截止、出清时间 |
| 飞书联动 | 7大专业智能体卡片、群消息同步、@智能体推送、智能问答 |

## 飞书智能体团队

平台推送自动@对应专业智能体：

- @政策研究与试点申报专员 — 政策跟踪、试点申报
- @绿电资源开发经理 — 绿电直连、PPA谈判
- @能效与液冷技术主管 — PUE优化、液冷选型
- @电力市场交易专员 — 现货套利、申报策略
- @资产证券化与融资经理 — REITs、绿色债券
- @算力调度与AI优化工程师 — 算电协同、AI制冷
- @合规与ESG认证专员 — 碳核算、ESG报告

## 技术栈

- **后端**: Node.js + Express
- **前端**: 原生 HTML/CSS/JS + ECharts
- **数据**: 内置2026年8月广东电力市场真实模拟数据
- **飞书集成**: lark-cli（消息推送、群消息同步、@智能体）

## 快速启动

```bash
# 安装依赖
npm install

# 启动服务
node server.js

# 或双击启动脚本
启动算电通.bat
```

访问 http://localhost:3000

## 数据说明

平台内置基于2026年8月广东电力现货市场的模拟数据，包括：
- 日前均价0.388元/kWh，峰0.823/谷0.200
- 100MW AI数据中心负荷模型（刚性45MW+弹性30MW+批处理10MW+制冷12MW+辅助3MW）
- 政策依据：42号令（2026.8.1施行）、34号文、73号文、650/688号文
